## Winning Pattern Analysis

Cross-referencing all winners across ADK Hackathon (2025), Vertex AI Agent Builder (2024), and Gemini API Developer Competition (2024), four traits recur:

### Pattern A: Hyper-specific real-world domain

Generic "AI assistant" or "chatbot for X" did NOT win. Every winner picks a **named, narrow, defensible domain**:
- Energy customer management (Energy Agent AI)
- Brazilian K-12 essay evaluation (Edu.AI)
- Trading hypothesis evaluation (TradeSageAI)
- Feynman diagram generation from natural language (Particle Physics Agent)
- ALS patient communication via eye-tracking (Gaze Link)
- Scam phone-call detection (ArthaRaksha)
- Cloud sustainability auditing (GreenOps)

**Anti-pattern that loses:** "AI agent for productivity" / "general Q&A bot" / "ChatGPT but for X."
**Pattern that wins:** "AI agent for [specific role + specific industry + specific painful outcome]."

### Pattern B: Multi-step workflow with autonomous action (not retrieval)

Winners DO things, not retrieve things. The judging rubric's "Technological Implementation" rewards visible orchestration of multiple steps:
- SalesShortcut: lead discovery → research → proposal generation → outreach (4-step pipeline)
- Edu.AI: essay evaluation + study plan generation + mock exam creation (3-agent orchestration)
- ArthaRaksha: live transcription → translation → scam classification → user alert (4-step real-time pipeline)
- GreenOps: continuous audit → forecast → optimization recommendations (closed loop)

**Anti-pattern that loses:** chat-and-respond, single-turn Q&A, "ask the docs."
**Pattern that wins:** the agent acts autonomously across 3+ steps to produce a concrete output the user couldn't have done themselves.

### Pattern C: Demo video shows the agent ACTING, not the developer narrating

ADK Hackathon judges explicitly weighted demo quality. Winners' videos:
- Show real autonomous execution (not pre-recorded slides)
- Demonstrate the multi-agent handoffs visibly (e.g., agent A planning → agent B executing → agent C verifying)
- Are tight (~3 min) and lead with the user-visible "wow"
- Often show a side-by-side or split-screen of "user's intent" vs "agent's autonomous chain of thought + actions"

**Anti-pattern that loses:** PowerPoint walkthrough, only architecture diagrams, founder talking to camera with no live action.
**Pattern that wins:** the camera shows the agent doing the work and the human watching in disbelief.

### Pattern D: Production-feeling polish at hackathon scope

Winners had:
- Custom UI (not a Streamlit/Gradio default skin)
- Their own domain or polished landing page (e.g., nexora-ai.de)
- Clean GitHub README with architecture diagram
- Sensible deployment (Cloud Run / Vertex AI / Agent Engine — visible Google Cloud surface area)
- A real "v1 of a startup," not "a hackathon prototype"

**Anti-pattern that loses:** localhost-only demo, default Streamlit, README that says "MVP for hackathon."
**Pattern that wins:** judges should think "I could see this being a real product."

### Bonus signal from ADK Hackathon honorable mentions

ALL three honorable mentions used **multi-service Google Cloud stacks** (ADK + Agent Engine + Cloud Run + Vertex AI). Single-service projects rarely placed. The hackathon rewards "you used the platform" not just "you used the framework."

### Applied to Rapid Agent Hackathon

Translation to current hackathon:

1. **Domain:** pick a specific role × industry × outcome. Don't say "MCP agent for MongoDB." Say "Compliance investigation agent for fintech ops teams — when a fraud signal hits, it autonomously queries MongoDB transaction history, cross-references GitLab ticket history, runs Arize evals on the model that flagged it, and produces a one-page incident report."
2. **Action:** 3+ step autonomous workflow producing a tangible artifact (report, deployment, fix, alert).
3. **Demo:** the agent acting on screen in real time. Not slides.
4. **Polish:** custom domain, clean repo, deployed on Cloud Run with the Agent Engine visible. License in repo (required).
5. **Stack breadth:** ADK + Gemini 3 + at least one partner MCP server (the bare minimum for compliance with rules) + 1-2 additional Google Cloud services (Cloud Run, BigQuery, Vertex AI Agent Engine) for breadth points.
