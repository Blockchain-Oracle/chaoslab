## Notes for coding agent

- This is THE judging surface foundation. Polish bar = "v1 of a startup," not "hackathon prototype." Don't skip the strict tsconfig — every later story relies on `noUncheckedIndexedAccess`.
- Use `pnpm dlx shadcn@latest init` interactively (or with `--defaults --base-color neutral --style new-york`) to bootstrap `components.json` + `lib/utils.ts`. Then `pnpm dlx shadcn@latest add button card badge dialog tabs scroll-area separator tooltip toast`.
- DO NOT install Framer Motion, visx, Zustand, TanStack Query, nuqs, or Playwright here — those land in their respective stories (7.4–7.6, 7.12). Keep this story focused on scaffold-only deps.
- `app/layout.tsx` must use `next/font/google` for Geist + Geist Mono (NOT a raw `<link>` tag — `next/font` self-hosts and prevents CLS per `best-practices/04 §11`). Bind to `--font-display` and `--font-mono` CSS variables so story-7.2's `@theme` block picks them up.
- `app/page.tsx` here is a PLACEHOLDER. Real landing page (hero + CTA + footer) lands in story-7.9. Just enough markup to make `curl` return 200.
- `app/globals.css` is JUST `@import "tailwindcss";` here. Story-7.2 fills in the full `@theme` block.
- The `next.config.ts` `headers()` block from `best-practices/04 §10` is REQUIRED (`X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `Permissions-Policy`).
- All files ≤400 LOC by construction; `layout.tsx` is the only file at risk and stays well under 80.
- Run `pnpm install` from the REPO ROOT, not from `apps/chaoslab-web/`. The pnpm workspace handles the rest.
- Pin `next@15.x`, `react@19.x`, `react-dom@19.x`, `tailwindcss@4.x`. Don't accept `^next@latest` without verifying with `pnpm view next version` first.
- The Context7 rule applies: before installing anything not in the `architecture.md` TS table, call `mcp__plugin_context7_context7__resolve-library-id` first.
